# Face Mask Detection using YOLOv8

## Project Overview
This project detects whether a person is wearing a face mask using the YOLOv8 deep learning model. The project was developed using Google Colab with NVIDIA GPU support and is stored on GitHub for version control.

## Technologies Used
- Python
- YOLOv8 (Ultralytics)
- OpenCV
- Google Colab
- GitHub
- NVIDIA GPU

## Features
- Detects faces with masks
- Detects faces without masks
- Real-time object detection
- Fast and accurate predictions
